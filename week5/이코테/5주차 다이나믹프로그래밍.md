## 다이나믹 프로그래밍
- 다이나믹 프로그래밍은 **메모리를 적절히 사용**하여 **수행시간 효율성을 비약적으로 향상시키는 방법**이다
- 이미 계산된 결과(작은 문제)는 별도의 메모리 영역에 저장하여 다시 계산하지 않도록 한다.
- 다이나믹 프로그래밍의 구현은 탑다운과 보텀업으로 구성된다.
탑다운: 위에서 아래로
보텀업: 아래에서 위로

- 다이나믹 프로그래밍 = **동적 계획법**
일반적인 프로그래밍 분야에서 **동적 할당(Dynamic Allocation)**은 **프로그램이 실행되는 도중에 실행한 필요한 메모리를 할당하는 기법**을 의미한다. 
반면, **다이나믹 프로그래밍**에서 **'다이나믹'은 별다른 의미 없이 사용된 단어**이다. 

### 다이나믹 프로그래밍의 조건
다이나믹 프로그래밍은 다음 조건을 만족할 때 사용할 수 있다. 
**1. 최적 부분 구조(Optimal Substructure)**
- 큰 문제를 작은 문제로 나눌 수 있으며 작은 문제의 답을 모아서 큰 문제를 해결할 수 있다.
**2. 중복되는 부분 문제(Overlapping Subproblem)**
- 동일한 작은 문제를 반복적으로 해결해야 한다. 

## 피보나치수열
다이나믹 프로그래밍으로 효과저긍로 계산할 수 있다. 
![](https://velog.velcdn.com/images/owlemily/post/8e1e73da-59ad-460f-9be6-9d9aaa9e42b4/image.png)
![](https://velog.velcdn.com/images/owlemily/post/45aabf02-4235-4431-a02a-cef8bf6c62ad/image.png)
피보나치 수열을 **단순 재귀**로 풀면 다음과 같다. 
```python
def fibo(x):
	if x==1 or x==2:
    	return 1
    return fibo(x-1) + fibo(x-2)
print(fibo(4))
```
피보나치 수열을 위와 같이 재귀함수로 해결하면 아래와 같은 시간복잡도를 가지게되고, 중복되는 부분 문제가 있다.

따라서 피보나치 수열을 **다이나믹 프로그래밍**으로 풀면 효율적으로 풀 수 있다. 
![](https://velog.velcdn.com/images/owlemily/post/6c812b27-a802-4314-809e-5b25f1d0dc18/image.png)
### Memoization
- memoization은 다이나믹 프로그래밍을 구현하는 방법 중 하나다. 
- 한 번 계산한 결과를 메모리 공간에 메모하는 기법이다.
- 같은 문제를 다시 호출하면 메모했던 결과를 그대로 가져온다. 
- 값을 기록해 놓는다는 점에서 캐싱(Caching)이라고 부른다. 
### 탑다운 vs 보텀업
- 탑다운 = 하향식 / 보텀업 = 상향식
- 다이나믹 프로그래밍의 전형적인 형태는 보텀업 방식이다. 
결과 저장용 리스트는 DP테이블 이라고 부른다. 
- Memoization은 이전에 계산된 결과를 일시적으로 기록해 놓는 넓은 개념을 의미한다. 
따라서 Memoization은 다이나믹 프로그래밍에 국한된 개념은 아니다. 
한번 계산된 결과를 담아놓기만 하고 다이나믹 프로그래밍을 위해 활용하지 않을 수도 있다. 
### 피보나치 수열: 탑다운 다이나믹 프로그래밍
```python
d = [0] * 100

#피보나치 함수를 재귀함수로 구현(탑다운 다이나믹 프로그래밍)
def fibo(x):
	# 종료 조건(1 혹으 2일때 1을 반환)
	if x==1 or x==2:
    	return 1
    # 이미 계산한 적 있는 문제라면 그대로 반환한다.
    if d[x] != 0:
    	return d[x]
    # 아직 계산하지 않은 문제라면 점화식에 따라서 피보나치 결과 반환
    d[x] = fibo(x-1) + fibo(x-2)
    return d[x]

print(fibo(99))
```
### 피보나치 수열: 보텀업 다이나믹 프로그래밍
```python
#앞서 계산된 결과를 저장하기 위한 DP 테이블 초기화
d = [0] * 100

# 첫번째 피보나치 수와 두번째 피보나치 수는 1
d[1] = 1
d[2] = 1
n = 99

#피보나치 함수(Fibonacci Function) 반복문으로 구현(보텀업 다이나믹 프로그래밍)
for i in range(3, n+1):
	d[i] = d[i-1] + d[i-2]

print(d[n])
```

### 다이나믹 프로그래밍 vs 분할정복
- 두가지 모두 **최적 부분 구조**를 가질 때 사용할 수 있다.
큰 문제는 작은 문제로 나눌 수 있으며 작은 문제의 답을 모아서 큰 문제를 해결할 수 있는 상황을 말한다.
- 두가지의 차이점은 **부분 문제의 중복**여부이다.
	
    - 다이나믹 프로그래밍 문제에서는 각 부분 문제들이 **서로 영향을 미치며 부분 문제가 중복**된다. 
    ex) 피보나치 수열 문제
    - 분할 정복 문제에서는 **동일한 부분 문제가 반복적으로 계산되지 않는다**. 
    ex) 분할정복의 대표적인 예시인 **퀵정렬**
    ![](https://velog.velcdn.com/images/owlemily/post/6a60f0e4-1ad5-435b-85f1-8459eeea90bd/image.png)
    피벗을 기준으로 정렬된 후에 왼쪽과 오른쪽이 재귀적으로 퀵정렬을 수행한다. 
    한번 분할이 이루어지면 피벗이였던 5는 더이상 다른 부분 문제에 포함되지 않고 정해진 위치가 변경되지 않는다.  
    

### 다이나믹 프로그래밍 문제 접근하는 방법
- 어떤 문제가 주어졌을 때 그리디, 구현, 완전탐색 등의 아이디어로 문제를 해결할 수 있을지 검토해본다. 
- 다른 알고리즘으로 풀이 방법이 떠오르지 않으면(예를들어, 완전탐색으로 시간복잡도가 너무 크거나 하다면) 그때 다이나믹 프로그래밍을 고려해보자. 
- 일단 재귀함수로 비효율적인 완전탐색 프로그램을 작성한 후에 (탑다운)작은 문제에서 구한 답이 큰 문제에서 그대로 사용될 수 있으면, 코드를 개선하는 방법을 사용할 수 있다. 
- 일반적인 코딩테스트 수준에서는 기본 유형의 다이나믹 프로그래밍 문제가 출제되는 경우가 많다. 
점화식을 떠올리는데 시간이 오래걸리는 문제가 제시될 수 있기 때문이다. 

### <예제1> - 개미전사
![](https://velog.velcdn.com/images/owlemily/post/b403b792-a3f7-4fe5-af35-1ae77efdf277/image.png)
![](https://velog.velcdn.com/images/owlemily/post/f67aafcf-d1ae-42d4-a5f3-58cd96c35000/image.png)
- $a_i = i$번째 식량창고까지의 최적의 해(얻을 수 있는 식량의 최대값)이라고 정의할 수 있다. 
- 위의 예제에서 DP 테이블은
$a_0$ = 1
$a_1$ = 3
$a_2$ = 3
$a_3$ = 8
- 다이나믹 프로그래밍 조건(1)최적부분구조, 2)중복되는 부분문제)이 성립된다.
i-1과 i-2의 상태를 고려해서 i번째 식량창고를 털지 말지를 결정할 수 있다. 
![](https://velog.velcdn.com/images/owlemily/post/36365e78-f3eb-4ba2-aa37-c6ae62580655/image.png)
- 최적부분구조: 큰 문제(i번째)를 위해 i-1, i-2와 같은 작은 부분을 활용한다.
- 중복되는 부분문제: i-3은 이미 앞쪽에서 고려가 되었기 때문에 중복되는 부분이다. 
![](https://velog.velcdn.com/images/owlemily/post/84d9b71e-d261-4eca-b53a-96cbc52d8042/image.png)
이런식으로 점화식을 세울 수 있다. 
```python
N = int(input())
ls = list(map(int, input().split()))
sum_food = [0] * N

for i in range(len(ls)):
    if i == 0:
        sum_food[i] = ls[i]
        
    if i == 1:
        sum_food[i] = max(ls[i], ls[i-1])
    else:
        sum_food[i] = max(ls[i-1], ls[i-2]+ls[i])


print(sum_food[-1])
```
### <예제2> - 1로 만들기
![](https://velog.velcdn.com/images/owlemily/post/8a16e9af-005f-4a07-a208-2fffca557f6c/image.png)
![](https://velog.velcdn.com/images/owlemily/post/963560c2-f7de-4d75-8d0a-f5fa390f684b/image.png)
이 문제는 다이나믹 프로그래밍을 만족하는지 조건을 따지는것이 나는 좀 복잡하게 느껴졌다. 
![](https://velog.velcdn.com/images/owlemily/post/c0eef288-0fdf-46da-9fbf-6f3832c1a9e5/image.png)
이 그림을 통해 **최적부분 구조**와 **중복되는 부분 문제**를 만족함을 알 수 있다. 
이런 형태를 따져보는 것을 기억하자. 
f(6)의 경우를 생각해보면 1을 빼는 경우, 2로 나눈 경우, 3으로 나눈 경우 이렇게 총 3가지로 생각해볼 수 있다. 
항상 모든 수에서 1을 빼거나 / 2로 나누거나 / 3으로 나누거나 / 5로 나누거나 이런 경우의 수를 생각할 수 있다.
![](https://velog.velcdn.com/images/owlemily/post/d196bee8-4d42-4466-9d1c-26b559d43dfc/image.png)
알고리즘 자체는 이해가 가는데 방법을 떠올리기가 어려웠다. 
```python
x = int(input())
d = [0]*30001

#다이나믹 프로그래밍 진행(보텀업 방식)
for i in range(2, x+1):
	#현재의 수에서 1을 빼는 경우
    d[i] = d[i-1] + 1
    #현재의 수가 2로 나누어 떨어지는 경우
    if i % 2 == 0:
    	d[i] = min(d[i], d[i//2]+1)
    #현재의 수가 3으로 나누어 떨어지는 경우
    if i % 3 == 0:
    	d[i] = min(d[i], d[i//3] + 1)
    #현재의 수가 5로 나누어 떨어지는 경우
    if i % 5 == 0:
    	d[i] = min(d[i], d[i//5] + 1)
    #4가지의 경우 중에서 가장 작은 값으로 min()을 통해서 갱신하도록 하였다. 
print(d[x])
```
### <예제3> - 효율적인 화폐 구성
![](https://velog.velcdn.com/images/owlemily/post/9c43c073-353b-4e5c-bb27-c2bf05de7974/image.png)
![](https://velog.velcdn.com/images/owlemily/post/15a208d2-85e6-42ee-a96a-ddb0495d9a79/image.png)
![](https://velog.velcdn.com/images/owlemily/post/b99d3f55-1e10-4cfc-a81c-55d20ac6e6be/image.png)
문제를 보고 느낀점은 M원을 만들기 위해 나는 M이라는 금액을 주어진 k화폐 단위로 조합하며 만드려고 노력한다.
그렇기 때문에 다이나믹 프로그래밍 풀이법을 잘 떠올리지 못하는데.. 
**이전에 나왔던 금액이면 이를 활용해서 다음 더 큰 금액의 화폐 개수를 바로 구할 수 있다는 것이다. **
- INF는 무한대의 값을 넣어주는 것을 의미한다.
- 이 문제는 이중 for문을 써서 시간복잡도가 $O(N^2)$이 된다.
문제에서 N과 M의 범위를 봐도 2중 for문이 괜찮다는 것을 알 수 있다. 
![](https://velog.velcdn.com/images/owlemily/post/0a12dfc9-46c7-4e1d-94f8-4cacd0e8c1cd/image.png)
![](https://velog.velcdn.com/images/owlemily/post/d417da1e-75f0-4017-b98d-194ddbf0d420/image.png)
![](https://velog.velcdn.com/images/owlemily/post/75f18314-14aa-4be1-8ff2-f993e89ad53d/image.png)
![](https://velog.velcdn.com/images/owlemily/post/57b48279-e6c3-4f0a-9a47-5cc5ca3b3eb4/image.png)
- 마지막의 경우 7원을 만들기 위해 더 작은 값들이 사용되었음을 알 수 있다.

```python
n, m = map(int, input().split())
#N개의 화폐 단위 정보 입력받기
array = []
for i in range(n):
	array.append(int(input()))
    
#한번 계산된 결과를 저장하기 위한 DP 테이블 초기화
d=[10001] * (m+1)

#다이나믹 프로그래밍 진행(보텀업)
d[0] = 0
for i in range(n):
	for j in range(array[i], m+1):
		if d[j-array[i]] != 10001: #(i-k)원을 만드는 법이 존재하는 경우
			d[j] = min(d[j], d[j-array[i]] + 1)
            
#계산된 결과 출력
if d[m] == 10001: #최종적으로 m을 만드는 방법이 없는 경우
	print(-1)
else:
	print(d[m])
	
```

### <예제4> - 금광 문제
![](https://velog.velcdn.com/images/owlemily/post/989c6394-90db-4c75-875d-3bb0ff26dafb/image.png)
![](https://velog.velcdn.com/images/owlemily/post/af91ef9b-b0a1-4660-9ed9-d71a818a5e7a/image.png)
![](https://velog.velcdn.com/images/owlemily/post/8090b07d-dfab-41b7-9181-65321766a72d/image.png)
![](https://velog.velcdn.com/images/owlemily/post/e44e86d3-865c-4a69-80ce-7c42b3d0c68d/image.png)
![](https://velog.velcdn.com/images/owlemily/post/8f6656ae-aa98-4db6-bd70-8a08ba402896/image.png)
```python
T = int(input())

for i in range(T):
    #금광 정보 입력
    n, m = map(int, input().split())
    array = list(map(int, input().split()))
    #다이나믹 프로그래밍을 위한 2차원 DP테이블 초기화
    dp = []
    index = 0
    for i in range(n):
        dp.append(array[index:index + m]) 
        index += m
    #다이나믹 프로그래밍 진행(보텀 업)
    for j in range(1, m): #열
        for i in range(n): #행
            #왼쪽 위에서 오는 경우
            if i == 0: left_up = 0 #0행이면 left_up은 없음
            else: left_up = dp[i-1][j-1]
            #왼쪽 아래에서 오는 경우
            if i == n-1: left_down = 0 #인덱스 벗어나나 확인
            else: left_down = dp[i+1][j-1]
            #왼쪽에서 오는 경우
            left = dp[i][j-1]
            dp[i][j] = dp[i][j] + max(left_up, left_down, left)

    result = 0
    for i in range(n):
        result = max(result, dp[i][m-1]) #제일 오른쪽 열에서 최대값 확인
    print(result)
```

### 불완전한 코드(처음 시도)
```python
N = int(input())
array = list(map(int, input().split()))
dp = [0] * N
dp[0] = array[0]
for i in range(1, N):
    if array[i] >= array[i-1]:
        dp[i] = 0
    else:
        dp[i] = array[i]
count = 0
for i in dp:
    if i == 0:
        count += 1

print(count)
```

- 코드 흐름(예시1)
```text
6
15 11 4 8 5 2

정답: 1
```
```text
i=0 → dp[0] = 15
i=1 → 11 < 15 → dp[1] = 11
i=2 → 4 < 11 → dp[2] = 4
i=3 → 8 >= 4 → dp[3] = 0
i=4 → 5 < 8 → dp[4] = 5
i=5 → 2 < 5 → dp[5] = 2
```
-> count = 1로 우연히 맞췄다
사실 틀리는 반례를 못찾았지만, 이전값 하나만 비교하는 코드이므로 부분 수열은 구하지 못한다. 


### 정답 코드
```python
n = int(input())
array = list(map(int, input().split()))

#순서를 뒤집어 '최장 증가 부분 수열' 문제로 변환
array.reverse()

#다이나믹 프로그래밍을 위한 1차원 DP 테이블 초기화
dp = [1] * n

#가장 긴 증가하는 부분 수열(LIS) 알고리즘 수행
for i in range(1, n):
	for j in range(0, i):
    	if array[j] < array[i]:
        	dp[i] = max(dp[i], dp[j] + 1)
#열외해야 하는 병사의 최소 수를 출력
print(n-max(dp))
```
